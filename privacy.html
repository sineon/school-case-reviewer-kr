1. 플러그인 운영 범위

본 플러그인은 ChatGPT 내 검토 지침과 참고자료로 구성됩니다. 별도의 AI 서버, 자체 계정, 외부 데이터베이스 또는 분석 추적 기능을 운영하지 않습니다. 개발자는 이용자의 ChatGPT 사안 입력·대화·첨부파일을 별도로 수집·저장하거나 제3자에게 제공하지 않습니다.

2. 입력 제한

학생 및 관련자의 이름, 학번, 연락처, 주소, 진단서, 상담기록, 얼굴이나 실제 사건을 특정할 수 있는 정보는 입력하지 마세요. 권한 있는 비식별 학교 규정과 필요한 최소한의 가상화된 사안을 사용하세요. 비식별화하더라도 조합으로 개인을 알아낼 수 있다면 입력하지 마세요.

3. 플랫폼에서의 처리

ChatGPT의 대화 처리, 보존 및 삭제는 이용자의 서비스 설정과 OpenAI의 정책에 따릅니다. 개발자는 이 설정을 대신 변경하거나 대화를 삭제할 수 없습니다. OpenAI 개인정보처리방침 및 이용 중인 계정의 데이터 제어 설정을 확인하세요. 공식 자료 검색 시 사건 식별정보를 검색어에 포함하지 않도록 요청합니다.

4. 문의 및 안내 사이트

안내 페이지에는 별도의 문의 제출 양식이나 분석 도구가 없습니다. GitHub Pages의 호스팅 및 GitHub 이슈는 GitHub의 개인정보 정책이 적용됩니다. 공개 이슈에 개인정보와 실제 사건 내용을 작성하지 마세요. 문의 또는 수정 요청은 지원 페이지를 이용하세요.

5. 변경

운영 방식이 변경될 경우 공개된 정책을 갱신합니다.

독립적인 교원 지원 도구 · 공식 교육기관 서비스가 아닙니다.
